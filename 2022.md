## Mission

A few years ago, I came across a quote from TJ Holowaychuk, a GitHub open source project author and full-stack engineer:

"I don't read books, never went to school, I just read other people's code and always wonder how things work".

From that moment on, I believed that reading source code, standing on the shoulders of those who came before us, and thinking about code architecture and program logic is the best way to improve programming skills.

Therefore, GitHub naturally became my favorite developer platform.

Driven by the original intention of uncovering the value of open source, GitHubDaily was officially founded on October 10, 2015.

Through this initiative, we hope to help developers discover the hottest open source projects, stay on top of the latest technology trends, broaden their technical horizons, and improve their programming skills by learning from open source projects.

To date, GitHubDaily has shared over 3,000 open source projects, covering but not limited to open source technical resources, developer tools, programming websites, and mature applications on GitHub.

In addition to GitHub, we have also started to help developers spread and share high-quality open source projects on the following social media platforms, exploring their future technological application prospects.

If you'd like to receive the latest GitHub open source project news, follow us below 👇

- WeChat Official Account: [GitHubDaily](https://raw.githubusercontent.com/GitHubDaily/GitHubDaily/master/assets/weixin.png)
- Weibo: [@GitHubDaily](https://weibo.com/GitHubDaily)
- Zhihu: [@GitHubDaily](https://www.zhihu.com/people/githubdaily)

> If you have great open source projects to share, feel free to recommend or self-nominate them via [issues](https://github.com/GitHubDaily/GitHubDaily/issues/new) in this repo. We look forward to your contributions.
