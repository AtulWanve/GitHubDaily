If we were to simply divide programmers into two categories — those who are completely confused by software design patterns and write code however they please, and those who wield design patterns with masterful ease and craft code as elegant as poetry —

Then the code written by the latter is far superior in maintainability and extensibility, and is also more elegant and readable.

In truth, writing code is a lot like handling the various big and small matters in our daily lives. When we follow a well-established thinking framework and action model, we find that many things become much easier to manage.

By now, it should go without saying just how important it is to learn design patterns well.

So, how do you go about learning design patterns effectively?

Below, Xiao G would like to recommend a website: Refactoring Guru.

![img](https://mmbiz.qpic.cn/mmbiz_png/uDRkMWLia28ialFxX7ibsIQGbVaOeSgZbwACvPNIicGPIB4FLicdlHbibHQNw7fnx1nBpLswPEVIY5fcf9opq4HWBUnA/640)

https://refactoring.guru/

This is a foreign website, originally created to help developers quickly and easily master various design patterns.

Refactoring Guru offers detailed explanations of 22 design patterns and 8 principles:
