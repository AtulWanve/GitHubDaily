For the Git tool, I believe many developers are familiar with it.

As the most popular distributed version control system today, Git has been beloved by countless developers since its inception in 2005. Over time, Git has evolved to become an essential tool for developers everywhere.

In 2007, three developers — Chris Wanstrath, PJ Hyett, and Tom Preston-Werner — built a website on the Ruby on Rails framework for hosting project source code: GitHub.

![img](https://mmbiz.qpic.cn/mmbiz_jpg/uDRkMWLia28h0MuaiaPYRah7VNBSXyxtMsnWb2H7K4D4yiafjBMqorVrawZ0lFgAqaagJCzxR6dIAHQyWz6ETefJQ/640)

Today, GitHub has become the world's largest developer community, where countless developers use Git for collaborative development every day. It has accumulated a wealth of high-quality open source projects, providing newcomers with valuable learning opportunities and reference material.

Therefore, learning to use Git is like buying a ticket to the world's top developer community.

Today, learning Git is no longer a difficult task. Looking back at when I first encountered Git, there was very little relevant material available on the Chinese internet, let alone people discussing open source projects on GitHub.

When I first got into Git and GitHub, I read a book called *Ruby on Rails Tutorial* by Michael Hartl. That book really opened a door to the tech world for me. The programming concepts and development techniques taught in it have benefited me to this day. If you're interested, go check it out.

However, text often lacks the expressive power of visuals, and the absence of real-time interactive feedback is one of its biggest drawbacks.

If you find learning Git boring and tedious, why not try a different approach? For example, learning the basics of Git through a game.

Today, I'd like to recommend a game: Learn Git Branching.

![img](https://mmbiz.qpic.cn/mmbiz_png/uDRkMWLia28h0MuaiaPYRah7VNBSXyxtMsxicic1iaWUF0nePMR4ZzH9OONxtUuNibNRBkr8sZOYgxEqbHzErJticHB0A/640)

Learn Git Branching was created by a developer and UC Berkeley graduate: Peter Cottle.

In this game, players need to work through a series of challenges to gradually master Git. Each level comes with a pre-set Git learning objective.

Once you're fully immersed and figuring out what to do next, mastering Git will be just around the corner.

Here's a demo:

The gameplay is fairly straightforward with no unnecessary bells and whistles. Together with the built-in virtual terminal environment and preview page, it lets us clearly see the real-time effect of each command.

This real-time interactive feedback experience undoubtedly helps developers feel the charm of Git in a more intimate way.

Meanwhile, developers from around the world have contributed translations of the project on GitHub, including Chinese, Japanese, Korean, and more.

A while back, all the code for this game was open-sourced on GitHub. If you want to dig into how it works, check it out:
