## Mission

Many years ago, I came across a statement by TJ Holowaychuk, a full-stack engineer and author of open-source projects on GitHub:

"I don't read books, never went to school, I just read other people's code and always wonder how things work".

From that moment on, I believed that reading source code and thinking about code architecture and program logic from the perspective of experienced developers is the best way to improve programming skills.

Therefore, GitHub naturally became my favorite developer platform.

With the original intention of exploring the value of open source, GitHubDaily was officially established on October 10, 2015.

Through this initiative, we hope to help developers discover the hottest open-source projects, stay on top of the latest technology trends, broaden their technical horizons, and improve their programming abilities through learning from open-source projects.

To date, GitHubDaily has shared over 3,000 open-source projects, covering (but not limited to) open-source technical resources, developer tools, programming websites, and mature applications on GitHub.

Besides GitHub, we have also started spreading and sharing high-quality open-source projects on multiple social media platforms to help developers discover their future application potential.

If you'd like to receive the latest GitHub open-source project news, follow us below 👇

- WeChat: [GitHubDaily](https://raw.githubusercontent.com/GitHubDaily/GitHubDaily/master/assets/weixin.png)
- Weibo: [@GitHubDaily](https://weibo.com/GitHubDaily)
- Zhihu: [@GitHubDaily](https://www.zhihu.com/people/githubdaily)

> If you have a great open-source project, feel free to recommend or self-nominate in the [issues](https://github.com/GitHubDaily/GitHubDaily/issues/new) of this repository. We look forward to your sharing.
