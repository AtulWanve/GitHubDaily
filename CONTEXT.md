# GitHubDaily Context

## Architecture and Structure
- The project serves as an archive of daily GitHub activity and articles.
- Yearly activities are logged in files like `2018.md`, `2019.md`, etc.
- The `articles/` directory contains individual blog posts or articles.
- The `assets/` directory is used for images and other static assets.
- The `resources/` directory contains additional project resources.

## Workflows
- Content is primarily in Markdown format.
- Translations and formatting updates are common activities.
